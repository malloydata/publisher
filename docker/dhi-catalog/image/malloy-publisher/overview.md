## About Malloy Publisher

Malloy Publisher is the analytics engine for [Malloy](https://malloydata.dev). It serves one or more Malloy
semantic model packages over a REST API (port 4000) and a single MCP endpoint (port 4040), compiles Malloy to
SQL, and runs it against the connected database: DuckDB (built in), BigQuery, Snowflake, Postgres, MySQL,
Trino, Databricks, DuckLake and more. It ships the Publisher Console, a browser UI on the REST port, and the
DuckDB CLI with the extensions the server loads baked in.
