    What it can discover

    The model as this identity is shown it. A domain whose lock cannot admit it is not listed at all, the same answer an agent's get_context call gets.

    What it can read

    The newest rows on the selected domain, read as this identity. Each column carries its classes. The same patients look completely different from one domain to the next: names and SSNs on the chart, a city and an age on the limited data set, a year and a three-digit ZIP on research.

    An agent acting for this identity

    An agent reaches this model through Publisher's MCP endpoint, with two tools that matter here: get_context to discover sources and fields, and execute_query to run Malloy. Neither is a side door. The gateway in front of the engine authenticates the person the agent works for and sets their #(secure) attributes on every call, so the agent never holds them and cannot change them. Every query it writes, however clever, runs through the same domains, locks and row filters as this page, and is recorded with the fields and classes it read.
